# DesignStack — каталог проверенных ресурсов для дизайнеров

Русскоязычный каталог инструментов, учебных материалов, ассетов и сообществ для UX/UI- и продуктовых дизайнеров. Отличается от десятков похожих списков тремя вещами:

- **ссылки живые** — каталог обходится скриптом еженедельно, у каждой записи стоит дата проверки;
- **про доступ сказано прямо** — открывается ли сервис из России, можно ли его оплатить и чем заменить, если нет;
- **цифры не выдуманы** — цена и размер набора берутся со страницы самого сервиса; чего проверить не удалось, остаётся пустым.

## Стек

WordPress 7.x · PHP 8.3 · блочная тема `designstack` (FSE) · плагин `designstack-core` · SQLite локально, MySQL 8 на хостинге.

Сборки нет: тема и плагин работают без npm-шага. Node нужен только для разовых проверок вроде `npx html-validate`.

## Запуск локально

```bash
python scripts/setup.py                                                          # портативный PHP, WordPress, WP-CLI
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Background # сервер на localhost:8080
python scripts/seed.py                                                           # демо-контент, если каталог пуст
```

Сайт — http://localhost:8080, админка — `/wp-admin`. Логин и пароль лежат в `.env` (в репозиторий не попадает, создаётся `setup.py`).

Остановить сервер: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1`.
Снести базу и поставить сайт заново: `python scripts/reset.py`.

## Структура

| Путь | Что внутри |
|---|---|
| `wordpress/wp-content/themes/designstack/` | тема: `theme.json` с токенами, шаблоны, паттерны, стили |
| `wordpress/wp-content/plugins/designstack-core/` | тип записи `resource`, поля, блоки, фильтры, SEO, разметка, Метрика |
| `scripts/` | среда (`setup`, `start`, `stop`, `reset`), наполнение, проверки |
| `docs/` | бриф, ТЗ, дизайн-система, аналитика, журнал решений |
| `.claude/` | навыки этапов, субагенты, правила кода и документов |
| `PROJECT.md` | состояние среды: репозиторий, хостинг, домен, счётчик |

В git попадает только своё. Ядро WordPress, портативный PHP, база, загрузки и `.env` восстанавливаются `scripts/setup.py`.

## Проверки

```bash
python scripts/check_tokens.py    # цвета и размеры только из theme.json
python scripts/check_voice.py     # тексты сайта без служебного языка
python scripts/check_links.py     # ссылки каталога живы
python scripts/screenshot.py <url>

# Цены и доступ — только российским взглядом: обе машины проекта выходят в сеть из Казахстана
ssh -f -N -D 1081 -o ExitOnForwardFailure=yes designstack   # туннель через сервер в РФ
python scripts/ru_browser_prices.py .tmp/список.txt         # браузер здесь, адрес российский
```

## Как ведётся работа

Проект собирается по конвейеру из девятнадцати этапов — от брифа до деплоя. Карта этапов и их состояние — `00_pipeline.md`, требования — `docs/brief.md`, журнал принятых решений с причинами — `docs/DECISIONS.md`.

Каждый этап живёт навыком в `.claude/skills/`: агент поднимает нужный сам по описанию задачи, а вызвать можно по имени — `/catalog-content digest`. Правила работы — `CLAUDE.md` и `01_principles.md`.

## Лицензия

Код темы и плагина — по решению владельца проекта. Содержимое каталога (оценки, подборки, тексты) принадлежит проекту DesignStack.
