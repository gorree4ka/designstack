# Директива: Генерация PRD и публикация в Notion

## Задача
Собрать все артефакты проекта в полноценный PRD и опубликовать как структурированную страницу в Notion с базами данных, views и профессиональным оформлением.

## Контекст

Прочитай все файлы проекта:
- Бриф (brief.md)
- Конкурентный анализ (competitive_analysis_final.md)
- UX-аудит (audit/audit_report.md), если есть
- Персоны (personas.md)
- Итоги интервью (interview_*.md), если есть
- Список фич (features_list.md)
- Приоритизация (prioritization.md)
- Scope MVP (mvp_scope.md)

## Инструкция

### Шаг 1 — Собрать PRD

На основе всех артефактов собери PRD со следующей структурой:

**1. Executive Summary**
- Одно предложение: что это за продукт
- Проблема, которую решаем (из брифа)
- Ключевой инсайт из исследования (из конкурентного анализа)
- Решение (из mvp_scope.md)
- Primary-персона и её JTBD

**2. Цели и метрики**
- 2-3 OKR (Objective + 2-3 Key Results каждый)
- North Star метрика

**3. Целевая аудитория**
- Краткое описание каждой персоны (3-4 предложения)
- Primary vs secondary
- JTBD каждой

**4. Конкурентный ландшафт**
- Краткая сводка: кто на рынке, в чём наше отличие
- Таблица ключевых дифференциаторов (из competitive_analysis_final.md)

**5. MVP Scope**
- Одно предложение — что входит в MVP
- Список Must have фич с описаниями
- Основной сценарий primary-персоны (шаги)
- Что осознанно НЕ входит (Should have → v1.1)

**6. User Stories**
Для каждой Must have фичи:
- Формат: «Как [персона], я хочу [действие], чтобы [результат]»
- Acceptance criteria (конкретные, проверяемые)
- Приоритет

**7. Нефункциональные требования**
- Производительность, безопасность, доступность — если применимо
- Платформы и устройства

**8. Риски и открытые вопросы**
- Из конкурентного анализа (threats)
- Из интервью (противоречия)
- Вопросы, которые требуют реального кастдева

**9. Roadmap**
- v1.0 (MVP): Must have фичи
- v1.1: Should have фичи
- v2.0: Could have фичи

### Шаг 2 — Опубликовать в Notion

Создай страницу в Notion со следующей структурой:

**Главная страница PRD:**
- Иконка: 📋
- Заголовок: «[Название продукта] — PRD v1.0»
- Оглавление (`<table_of_contents/>`)
- Executive Summary в callout-блоке (`<callout icon="⚡" color="yellow_background">`)
- Секции с заголовками H2
- Конкурентные дифференциаторы — таблица
- MVP scope — список с to-do чеклистами для acceptance criteria
- Детали user stories — в toggle-блоках (`<details>`)
- Риски — в callout-блоке (`<callout icon="⚠️" color="red_background">`)
- Roadmap — таблица с колонками: Версия, Фичи, Приоритет

**Встроенная база данных «User Stories»:**
- Свойства: Title, Priority (Must/Should/Could/Won't), Persona, Status (To Do/In Progress/Done)
- Заполни строками из user stories
- Создай Board view, сгруппированный по Priority

**Встроенная база данных «Feature Roadmap»:**
- Свойства: Feature (title), Version (v1.0/v1.1/v2.0), Priority, Description
- Заполни из приоритизации
- Создай Table view

## Формат результата

1. PRD-контент сохрани локально в `prd.md`
2. Опубликуй в Notion как структурированную страницу
3. Верни ссылку на созданную страницу
