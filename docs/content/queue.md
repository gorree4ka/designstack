# Очередь каталога

Журнал редакции: кандидаты, черновики, решения и — главное — **источник каждого статуса**. Заведена 14.09.2026, директива 16, режим `recheck`.

Правила ведения:

- Строка пишется в том же запуске, в котором принято решение. Не записал источник — считай, что проверки не было.
- Этап: `кандидат` → `черновик #id` → `утверждён` / `отклонён`. Для уже опубликованных записей — `перепроверен`.
- Колонка «доступ из РФ + источник» заполняется тремя пробами фазы 1.5: ответ сайта с российского IP (`scripts/check_ru_access.py`), справка вендора, способ оплаты. Меньше трёх — пишем, каких не хватает.
- Цифра без источника в очереди — та же выдумка, что цифра без источника в карточке.
- Цена снимается **только российским взглядом**: разметку читает `scripts/ru_prices.py` с сервера, страницы на JavaScript — `scripts/ru_browser_prices.py` (браузер здесь, трафик через туннель `ssh -f -N -D 1081 designstack`). Обе машины проекта выходят в сеть из Казахстана, и кадр из любого местного браузера источником цены для России не является.

### Находка партии: разделитель тем повисал отдельной строкой

Первая же опубликованная карточка показала дефект вёрстки, живущий с этапа 13: в блоке фактов строка «Темы» выводилась тремя строками — ссылка, одинокая «·», ссылка. Причина не в контенте: `.ds-facts__value` — flex-колонка, и каждый инлайновый ребёнок становится отдельным flex-элементом, так что неразрывный пробел перед разделителем не помогает. Список ссылок теперь отдаётся одним `<span class="ds-facts__inline">`. Проверено на 1440 и 375: одна строка вместо трёх на всех карточках. Правило со способом проверки — `.claude/rules/wp-theme.md`, §10.

### Находка партии: поля `curator` в модели нет

Бриф §5.1 описывает `curator` как «автор WP», то есть `post_author`, а не мета-поле. 14.09.2026 подпись была записана метой во все 28 записей — она нигде не читалась, потому что подпись на странице ресурса ставит шаблон. Мета удалена, D91 исправлено. Автор всех 40 записей сейчас — `admin`; когда кураторов станет больше одного, заводим пользователей WordPress, а не поле.

### Третья правка: слова «VPN» на сайте больше нет

Решение заказчика (D115): про VPN не пишем нигде. Способы открыть закрытое существуют, но это не наша тема — мы говорим, что сервис недоступен, и называем замену.

Плюс код: метка `vpn_only`, её расшифровка и расшифровка `open` («открывается без VPN» → «открывается напрямую»), три паттерна витрины.

Как переписан ключевой кусок подборки:

| было | стало |
|---|---|
| Если сайт закрыт для России, поможет VPN. Если сервис закрылся вообще — VPN бесполезен | Одно дело, когда сервис жив, но закрыл двери для России: продукт существует, им пользуются, просто не мы. Совсем другое — когда он закрылся насовсем: искать нечего |

Кнопка «Перейти на сайт» у недоступных записей остаётся (D116): сервис жив, и человек вправе дойти до него сам. У закрытых навсегда её по-прежнему нет — идти некуда.

## Российский браузер: как достали остальные цены — 15.09.2026
