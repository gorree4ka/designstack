# Эталоны визуального направления

Этап 09, фаза B, 11.09.2026. Три эталона одной плотности:
- Toools.design и uxtools.co — из брифа §8;
- каталог шрифтов Google Fonts — из другой ниши.

У каждого снято:
- четыре типа страниц: плотный список, пустое состояние, страница действия, форма;
- список на 375.

**Как снимали.** Кадры — Playwright, окно 1440×900 или 375×812. Если нужная часть страницы ниже первого экрана, кадр обрезан сверху до указанной высоты. Каждый кадр открыт и проверен глазами. Замеры — вычисленные стили элементов на тех же страницах, в px. Полные JSON с селекторами лежат в scratchpad сессии, в репозиторий не входят.

**От эталона берём механику, а не внешний вид:** тексты, картинки и компоновку не переносим. Итог разбора — `docs/brand/brand-direction.md`, лист выбора — https://claude.ai/code/artifact/25a7dd3a-33ac-4f71-9a30-37986189205f

## Что берём и что не берём

- **Toools.design.**
  - Берём: цену тихой меткой в одном и том же месте карточки; чипсы категорий над списком; одну колонку формы с подписью над полем и счётчиком знаков; зазор между карточками.
  - Не берём: свечения, зерно, градиентные кольца и сиреневую подложку; радиус 28 и мягкие тени у всего; плавающую шапку-«таблетку»; бледные подписи капсом; строку текста в 106 знаков.
- **uxtools.co.**
  - Берём: данные моноширинным шрифтом с короткой подписью; линии 1 px вместо теней; крупный заголовок при спокойном тексте; пару «залитая и контурная кнопка»; строку, которая на телефоне становится карточкой.
  - Не берём: тёмную сцену по умолчанию и два неоновых акцента; нулевой радиус и крестики-разметку; моноширинный капс с разрядкой; цветные плашки 404.
- **Google Fonts.**
  - Берём: число выдачи; активный фильтр чипсом с крестиком и «Clear filters» рядом; пустую выдачу, которая называет фильтр и даёт сброс; одну залитую кнопку на экран; тень только у выезжающей панели.
  - Не берём: пилюли у всех кнопок и полей; голубые подложки панелей; шрифтовой смайлик в пустой выдаче; боковую навигацию приложения.
