# Инвентарь страниц DesignStack

Версия 1 от 11.09.2026, входы: spec 1.0, brief 1.1. Этап 07, фаза 1.1. Статус: утверждён заказчиком 11.09.2026 (фаза 1.1); успех формы — отдельная страница `suggest-thanks`, выбор заказчика.

Одна страница — одно место в дереве — один шаблон WordPress — один URL. Если чего-то из четырёх нельзя назвать, это не страница, а состояние другой страницы, функция после MVP или открытый вопрос (`docs/ia/open-questions.md`).

**Как читать столбец «Состояния».** Для списков: данные / пусто / ошибка / переполнение. Для форм: по умолчанию / ошибки полей / отправка / успех / ошибка отправки. Страницы собираются на сервере, поэтому «ошибка» у списка — это не сбой загрузки, а неверный адрес: несуществующая запись, номер страницы за пределами, неизвестное значение фильтра. Что именно показать в каждом состоянии, решают этапы 08 и 14.

## 7. Итог

- Страниц в MVP — 20: из ТЗ 16, служебных 4.
- Шаблонов — 12 и запасной `index.html`: `front-page`, `taxonomy-resource_type`, `single-resource`, `taxonomy-topic`, `search`, `category`, `single`, `page-about`, `page-suggest`, `page`, `page-styleguide`, `404`.
- Допущение фазы: один шаблон `taxonomy-resource_type.html` на четыре раздела. Наборы фильтров разные, но панель фильтров — один блок плагина, который читает текущий раздел. Отдельные `taxonomy-resource_type-{term}.html` появятся, только если на этапе 08 раскладки разделов разойдутся не только фильтрами.
- Допущение фазы: один `category.html` на подборки, дайджест и обзоры и один `single.html` на их записи. WordPress сам подхватит `category-{slug}.html`, если архивы разойдутся; для записей тогда нужен выбор шаблона по категории — требование к 12 и 13.
- Страниц после MVP в дорожной карте — 4, в подсчёт не входят.
