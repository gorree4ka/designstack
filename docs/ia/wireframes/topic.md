**Фильтр типа дал ноль** — `/topic/prototyping/?resource_type=community`: число выдачи «0 ресурсов»; H2 «Сообществ по теме „Прототипирование“ пока нет»; кнопка «Сбросить фильтры» ведёт на адрес без параметра; ссылка «Предложить ресурс»; `noindex`.

**Неверный адрес:** несуществующая тема или страница за пределами — шаблон 404.

## Решения состава

- Фильтр по типу — ряд ссылок, а не форма с «Применить» — решил так, потому что выбирается одно значение из пяти: ссылка работает без JavaScript и сразу даёт адрес `?resource_type=tool` (US-10).
- Один тип за раз — решил так, потому что выборку нескольких типов по теме никто не просит, а раздел по типу уже есть в меню.
- Остальных фильтров нет — решил так, потому что по ТЗ на странице темы фильтруется только тип (F-05, F-10), а цену и доступ фильтруют в разделе.
- Сетка на всю ширину в 3 колонки, как в разделе — решил так, потому что карточка одна и ритм списков один.
- Выдача смешанная, с бейджем типа у карточки, а не группами по типам — решил так, потому что группы ломают пагинацию и число на странице. Спорное: группы удобнее, чтобы собрать окружение под задачу, — вынести на лист решений.
- Описание темы под заголовком — решил так, потому что страница темы индексируется (F-22) и без текста поисковику нечего показать; нет описания — нет блока.
- Порядок по умолчанию — сначала недавно проверенные, как в `tools.md`.
