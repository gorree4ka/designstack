## Пустое состояние

**Фильтры дали ноль** — `/tools/?topic=prototyping&ru_payment=ru_native`:
- Панель фильтров и чипсы остаются на месте, число выдачи — «0 ресурсов».
- Вместо сетки: H2 «По таким условиям ничего нет»; текст с активными фильтрами: «Российских инструментов для прототипирования в каталоге пока нет. Попробуй снять фильтр „Российский“.»; кнопка «Сбросить фильтры»; ссылка «Предложить ресурс».
- Ниже, если среди фильтров есть тема: H2 «Прототипирование без других фильтров» и до 6 карточек этой темы (US-19).
- Страница отдаёт 200 и `noindex` (US-16).

**Раздел пуст** — до наполнения каталога: H2 «В разделе пока нет ресурсов», ссылка «Предложить ресурс»; панели фильтров и пагинации нет.

**Неверный адрес:** страница пагинации за пределами, например `/tools/page/99/`, — шаблон 404; неизвестное значение фильтра игнорируется, чипс для него не выводится.

## Решения состава

- Фильтры колонкой 280 слева от 900 и панелью снизу до 900 — решил так, потому что групп шесть: над списком они заняли бы весь первый экран (brief §8, US-18).
- Кнопка «Применить» есть всегда — решил так, потому что без JavaScript форма фильтров работает только через неё (US-16, критерий 5); применять ли фильтры сразу при клике с JavaScript, решает этап 14.
- Счётчиков у значений фильтров нет — решил так, потому что ТЗ требует только общее число выдачи (US-17), а счётчик у каждого значения — лишние запросы к базе при 50 инструментах.
- 18 карточек на странице — решил так, потому что число делится на 3 и на 2 колонки без дыр в рядах, а 50 инструментов — это три страницы.
- Бейдж типа в карточке остаётся и внутри раздела — решил так, потому что карточка одна на все списки (US-26), а на странице темы и в поиске тип нужен.
- Вердикт сразу под названием, выше меток — решил так, потому что он отвечает «брать или нет» одной строкой (обещание 3 брифа).
- Дата проверки и «Перейти на сайт» в одной нижней строке — решил так, потому что дата — последнее, что стоит увидеть перед переходом на сайт (обещание 1).
- Порядок по умолчанию — сначала недавно проверенные, переключателя сортировки нет — решил так, потому что переключатель — v1.1 (F-21), а свежая проверка сверху поддерживает обещание актуальности. Спорное: вынести на лист решений.
- Поле поиска в шапке раскрыто только от 1200 — решил так, потому что семь пунктов меню, логотип и поле с кнопкой в меньшую ширину не помещаются.
