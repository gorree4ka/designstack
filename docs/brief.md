## 1. Контекст продукта

Русскоязычный сайт-каталог проверенных ресурсов для дизайнеров интерфейсов: инструменты, учебные материалы, ассеты, сообщества. Первичная аудитория — junior-дизайнеры и люди, переходящие в профессию. Каждая запись имеет редакторскую оценку от имени куратора, дату последней проверки и две метки — открывается ли из России и можно ли оплатить — с локальными аналогами. Вокруг каталога — статейные форматы (подборки, еженедельный дайджест, обзоры), которые дают поисковый трафик и распространяются через Telegram. Первой функцией после запуска станет проверка уровня: дизайнер оценивает свои навыки по нашей карте и получает программу развития из материалов каталога. Цель на год — медиа-проект с растущим трафиком; монетизация откладывается до заметной аудитории. В рунете обновляемого структурированного сборника такого рода нет, ниша свободна.

**Три обещания сайта** (подтверждены дырами 1, 5, 6 исследования):
1. **Актуальность.** У каждой записи видна дата проверки и статус: работает, изменились условия, закрыт. Каталог не «гниёт».
2. **Доступность из РФ.** Две метки — открывается ли сайт из России и можно ли оплатить (D15) — и ссылка на локальный аналог рядом с каждым зарубежным ресурсом. Метки ставятся только по проверке с российского IP (O8).
3. **Редакторская оценка.** Не описание с сайта вендора, а 2–3 предложения куратора: кому подходит, за что, чем хуже альтернатив.

**Позиционирующая фраза (рабочая):** «Проверенные ресурсы для дизайнеров: что работает, что работает из России и почему мы это советуем».

## 5. Контентная модель

### 5.1 Тип записи `resource` (единый post type, тип задаётся таксономией)

Один post type `resource` с обязательной таксономией `resource_type` из четырёх значений: `tool` (инструмент/сервис), `learning` (учебный материал), `asset` (ассет/шаблон), `community` (сообщество/канал/рассылка/вакансии). Единый тип упрощает общий поиск и фильтры, а поля, специфичные для типа, показываются условно.

**Общие поля** (post meta):

| Поле | Тип | Назначение |
|---|---|---|
| `url` | URL | Ссылка на ресурс (в MVP без партнёрских параметров) |
| `verdict` | строка ≤ 120 симв. | Одна фраза-вывод в карточке: «Лучший бесплатный старт для прототипов» |
| `review` | текст 2–4 предложения | Редакторская оценка: кому, за что, минусы, чем хуже альтернатив |
| `pricing` | enum: free / freemium / paid / trial | Модель оплаты |
| `price_note` | строка | «от $12/мес», «бесплатно для студентов» |
| `ru_open` | enum: `open` (да) / `vpn_only` (только с VPN) / `blocked` (заблокирован) | Открывается ли сайт из России (D15); ставится только по проверке с российского IP |
| `ru_payment` | enum: `payable` (да) / `no_payment` (нет) / `ru_native` (российский сервис); у бесплатного ресурса не заполняется (D28) | Можно ли оплатить из России (D15); значение «через карту СНГ или посредника» — предложение P14, решить до этапа 12 |
| `ru_alternative` | связь с `resource` (0..n) | Локальный или доступный аналог; структура связи из шести полей — предложение P12, решить до этапа 12 |
| `language` | enum: ru / en / multi | Язык интерфейса или материала |
| `checked_at` | дата | Дата последней проверки, показывается в карточке |
| `status` | enum: active / changed / dead | Активен / изменились условия / закрыт (не удаляем, помечаем) |
| `curator` | автор WP | Кто оценивал; выводится с именем и ролью |
| `affiliate_url` | URL (пусто в MVP) | Заложено для будущих партнёрок, не используется до решения о монетизации |

**Поля по типу:**
- `tool`: `platforms` (web / mac / win / ios / android / figma-plugin), `has_free_tier` (да/нет), `ai_features` (да/нет).
- `learning`: `format` (course / book / article / video / podcast / guide), `level` (junior / middle / senior), `duration` («6 часов», «300 страниц»), `certificate` (да/нет).
- `asset`: `license` (free-commercial / personal-only / CC-BY / paid), `file_format` (Figma / Sketch / SVG / OTF…), `cyrillic` (да/нет/частично), `assets_count`.
- `community`: `platform` (Telegram / Discord / сайт / рассылка), `audience_size` (оценка, дата), `activity` (ежедневно / еженедельно / реже), `is_jobs` (да/нет).

**Таксономии** (общие для всех типов):
- `resource_type` — тип (4 значения, иерархии нет).
- `topic` — тема, иерархическая: UX-исследования, Прототипирование, UI и визуал, Типографика, Иконки и иллюстрации, Дизайн-системы, AI для дизайнера, Аналитика и метрики, Карьера и портфолио, Доступность, Мобильный дизайн, Веб и лендинги.
- `level` — junior / middle / senior (для всех типов: «для кого»).
- `skill` — навык нашей карты (D22, D23, D24), иерархический: область → навык. Размечается у ресурсов всех типов; у учебных материалов — ещё уровень владения, до которого материал поднимает навык (D26). Как хранить связь ресурса, навыка и уровня, проверяется пробой на этапе 12; показ в интерфейсе MVP решает этап 06.
- `tag` — свободные теги (стандартные метки WP).

### 5.2 Статейные форматы (стандартные записи `post` с категориями)

| Категория | Что это | Ритм | Связь с каталогом |
|---|---|---|---|
| `Подборки` | «12 бесплатных инструментов для прототипирования в 2026», SEO-ядро | 8–10 к запуску, затем 2–4 в месяц | Блок «список ресурсов» тянет карточки из `resource` по выбранным ID/тегам; обновление записи обновляет подборку |
| `Дайджест` | Новое и обновлённое за неделю + 3–5 находок | Еженедельно, тот же текст в Telegram и рассылку | Автосборка черновика из записей с `checked_at`/`date` за неделю |
| `Обзоры` | Лёгкие обзоры и сравнения 2–3 инструментов | 1–2 в месяц; глубокие тесты после MVP | Ссылки на карточки, итоговая таблица сравнения |

### 5.3 Редакционный процесс

1. **Сбор.** Claude по запросу куратора или по расписанию ищет кандидатов (новые инструменты, обновления, запросы через форму «предложить ресурс»), проверяет живость, заполняет все поля черновика, пишет черновик `review` и `verdict`, проставляет `ru_open` и `ru_payment` по трём пробам — ответ сайта с российского IP, справка вендора, способ оплаты — и навыки карты.
2. **Утверждение.** Куратор читает черновик, правит оценку, ставит `checked_at`, публикует. Ничто не публикуется без ручного утверждения.
3. **Переподтверждение.** Скрипт раз в неделю проверяет URL всех записей; записи с `checked_at` старше 90 дней попадают в очередь на перепроверку; сменившие условия помечаются `changed`, закрытые — `dead` с предложением аналога. Доступность из России перепроверяет скрипт `scripts/check_ru_access.py` с сервера Beget: он сначала замеряет страну IP и без российского IP не запускается (O8, D25).
4. **Стартовое наполнение (MVP):** инструменты 50, учебные материалы 40, ассеты 30, сообщества 20 — итого 140 записей; 8–10 подборок; 2 дайджеста-образца.

## 6. Информационная архитектура

```
/                      Главная: поиск, 4 типа, «проверено на этой неделе», свежие подборки, подписка на дайджест
/tools/                Инструменты — архив с фильтрами (тема, цена, открывается из РФ, оплата из РФ, платформа, уровень)
/learn/                Учебные материалы — фильтры (формат, уровень, язык, цена)
/assets/               Ассеты — фильтры (лицензия, формат, кириллица)
/community/            Сообщества и каналы — фильтры (платформа, вакансии)
/resource/{slug}/      Страница ресурса: вердикт, оценка, поля, доступ и оплата из РФ, аналоги, дата проверки, «похожие»; сюда ведёт клик по карточке в списке (D16)
/topic/{slug}/         Тема: все типы по теме (UX-исследования и т. п.)
/collections/          Подборки; /collections/{slug}/
/digest/               Дайджест; /digest/{slug}/
/reviews/              Обзоры и сравнения
/about/                О проекте: куратор, принципы оценки, как проверяем, как попасть в каталог
/suggest/              Предложить ресурс (форма без регистрации)
/search/?s=            Поиск по всему
```

Навигация: шапка — Инструменты, Учёба, Ассеты, Сообщества, Подборки, Дайджест, О проекте; поле поиска; переключатель темы. Подвал — подписка, Telegram, принципы, политика данных. Хлебные крошки на всех внутренних страницах.

## 7. Технические требования (WordPress)

- **Ядро:** WordPress 7.x, PHP 8.3, MySQL 8 на продакшене (локально SQLite; перед запуском обязательный прогон на MySQL, MySQL-специфичный SQL не писать).
- **Тема:** собственная блочная тема `designstack` (FSE): `theme.json` с токенами, шаблоны `templates/`, части `parts/`, паттерны `patterns/`. Без page-builder'ов.
- **Данные:** собственный плагин `designstack-core`: post type `resource`, таксономии, meta-поля через `register_post_meta` с панелью в редакторе, блок «список ресурсов» для подборок, блок «фильтры архива», шорткод/блок «статус из РФ». Данные живут в плагине, чтобы не зависеть от темы.
- **Фильтры и поиск:** серверные, через query vars и `tax_query`/`meta_query`; URL фильтров индексируемые и шарящиеся; JS только для прогрессивного улучшения. Пагинация — с адресами страниц (`/tools/page/2/`, `rel=next`), без бесконечной ленты (D17). Поиск — штатный WP по названию, вердикту, оценке; при росте — расширить индекс мета-полей.
- **Аккаунты:** нет регистрации пользователей в MVP. Ничего не прячем за регистрацией и потом: что за ресурс, цена, доступ из РФ и оценка куратора видны всем и всегда (D18). Роли: администратор, куратор (editor), автор.
- **Формы:** «предложить ресурс» — собственный блок в `designstack-core` с nonce, honeypot, лимитом по IP; письмо куратору + запись в очередь черновиков.
- **Рассылка:** внешний российский сервис (Unisender или Sendsay — выбрать), форма подписки через API; персональные данные — согласие и политика.
- **Плагины (минимум):** SEO (Yoast SEO или Rank Math — один), кеширование (по возможностям хостинга, иначе WP Super Cache), Redirection, резервные копии (UpdraftPlus или средства хостинга). Всё остальное — в `designstack-core`.
- **Хостинг:** Beget (D25), PHP 8.3, MySQL 8, HTTPS (Let's Encrypt), SSH и WP-CLI, cron. Тариф выбрать так, чтобы по SSH запускались Python-скрипты с исходящими запросами, и проверить это пробой: с этого сервера `scripts/check_ru_access.py` проверяет доступность из России, потому что заказчик работает через VPN (O8). Домен — после выбора названия.
- **Производительность:** Core Web Vitals в зелёной зоне (LCP < 2,5 с, CLS < 0,1); изображения WebP с ленивой загрузкой; иконки ресурсов — фавиконы/логотипы в едином размере; никаких тяжёлых JS-библиотек.
- **SEO:** ЧПУ, schema.org (`SoftwareApplication` для инструментов, `Course` для курсов, `ItemList`/`CollectionPage` для подборок), Open Graph, sitemap, канонические ссылки для фильтров, `noindex` для пустых фильтров.
- **Аналитика:** Яндекс Метрика (вебвизор выключен), цели: переход по ссылке ресурса, подписка, отправка формы.
- **Резервные копии:** ежедневно на хостинге + еженедельный экспорт за пределы; проверка ссылок — cron-скрипт (WP-CLI) раз в неделю.
- **Безопасность:** `DISALLOW_FILE_EDIT`, обновления ядра/плагинов вручную после проверки на локальной копии, 2FA для куратора.

## 8. UI-требования

- **Характер:** чистый утилитарный каталог, контент на первом месте; референсы — Toools.design, uxtools.co. Много воздуха, сдержанная нейтральная палитра с одним акцентным цветом, без иллюстраций-«декора».
- **Темы:** светлая и тёмная, переключатель в шапке, по умолчанию по системной настройке; все цвета — токены в `theme.json`.
- **Токены (стартовые, уточняются при дизайне):** нейтральная шкала серых 50–950; акцент один (подобрать при неймингe); статусы: зелёный — открывается и оплачивается, жёлтый — изменились условия или только с VPN, красный — закрыт, заблокирован или не оплатить; у двух полей доступа (D15) — по своей метке. Шрифт с кириллицей: Inter (переменный) или Golos Text; моноширинный для ценников — JetBrains Mono. Сетка карточек 3 / 2 / 1 колонка; базовый отступ 8 px; радиус 8–12 px.
- **Карточка ресурса:** логотип, название, тип, вердикт, метка цены, две метки доступа из РФ — открывается и оплата (D15), дата проверки, 2–3 тега, кнопка «Перейти на сайт»; клик по карточке ведёт на страницу ресурса (D16). Одинаковая по высоте, без описания с сайта вендора.
- **Фильтры:** панель слева на десктопе, чипсы и выезжающая панель на мобильных; активные фильтры отражены в URL.
- **Доступность:** WCAG 2.2 AA, контраст ≥ 4,5:1 в обеих темах, полная клавиатурная навигация, видимый фокус, статусы не только цветом (иконка + текст), `prefers-reduced-motion`.
- **Типографика по-русски:** «ёлочки», буква ё, неразрывные пробелы перед короткими словами, тире.
- **Адаптивность:** mobile-first, брейкпоинты 600 / 900 / 1200.

## 9. Рост и дистрибуция

- **SEO-кластеры.** Замер Wordstat 10.09.2026 (`docs/research/wordstat.md`; регион «Все регионы», средний объём апреля–августа 2026 и изменение к тому же периоду 2025 года): «шрифты с кириллицей» — около 3 800 запросов в месяц, −24 %; «{сервис} в России» — около 480, +50 %, единственный растущий кластер; «курсы UX/UI бесплатно» — около 210, −70 %. Не замерены: «инструменты для UX-дизайнера», «бесплатные UI-киты Figma», «аналог {сервис} в России», «как оплатить {сервис} из России», «телеграм-каналы для дизайнеров». Каждая подборка — под один кластер; каждая страница ресурса — под запрос «{название} обзор / аналоги». Замер с регионом «Россия» — на этапе 17.
- **Telegram-канал** создаётся вместе с сайтом: дайджест + 2–3 карточки в неделю со ссылкой на сайт.
- **Рассылка:** запуск после 300 подписчиков в Telegram или 1 000 визитов в месяц.
- **Кросс-постинг:** подборки на vc.ru, Habr, Дизайн-кабак со ссылкой на источник.
- **Партнёрства (после MVP):** школы, студии, авторы каналов — обмен упоминаниями; без коммерции до решения о монетизации.

## 10. Бизнес и метрики

Цель года — медиа-проект с растущим трафиком. Монетизация не включается до заметного трафика; поля для партнёрских ссылок заложены, но пусты. Все будущие партнёрства и спонсорства — с явной маркировкой и без влияния на оценку.

| Горизонт | Ключевые результаты |
|---|---|
| Запуск (4–6 недель) | 140 записей, 8–10 подборок, 2 дайджеста, Telegram-канал, Метрика и sitemap |
| 3 месяца | 200 записей; 12 дайджестов подряд; 1 000 визитов/мес; 300 подписчиков в Telegram; 100 % записей с `checked_at` не старше 90 дней |
| 12 месяцев | 500 записей; 40 подборок; 10 000 визитов/мес из поиска; 3 000 подписчиков в Telegram; 1 000 в рассылке; 25 % возвращающихся; решение о монетизации на основе данных |

Все цифры — целевые оценки, не прогноз. Цель 10 000 визитов в месяц из поиска ставилась до замеров: с апреля 2026 крупные фразы темы на 24–34 % ниже прошлого года (`docs/research/wordstat.md`), поэтому её пересчитывают на этапе 17 по объёмам кластеров с регионом «Россия».

## 11. MVP и дорожная карта

**В MVP:** каталог из 4 типов с фильтрами, страница ресурса с оценкой, доступом и оплатой из РФ, аналогами и датой, темы, подборки, дайджест, лёгкие обзоры, страница «О проекте», форма «предложить ресурс», поиск, светлая и тёмная темы, SEO-разметка, Метрика, Telegram-канал, скрипт проверки ссылок; основа проверки уровня — список навыков нашей карты, шкала уровней и разметка ресурсов при наполнении (D22, D26).

**Не в MVP:** аккаунты пользователей, UGC, комментарии, рейтинги пользователей, глубокие обзоры-тесты, разборы «почему так» (H2), AI-UX хаб (H5), проверка уровня и программа развития (H6) — первой функцией после запуска, в v1.1, многоязычность, монетизация.

| Неделя | Веха |
|---|---|
| 1 | Название и домен, карта сайта, дизайн-токены и макет карточки/архива, плагин `designstack-core` (типы, таксономии, поля), список навыков и шкала уровней для разметки |
| 2–3 | Тема `designstack`: шаблоны, фильтры, карточка, подборки, форма; первые 50 записей (инструменты) |
| 4 | Наполнение до 140 записей, 8–10 подборок, 2 дайджеста; SEO-разметка; Метрика; тариф Beget куплен, доступность записей из России проверена с него до публикации |
| 5 | Перенос на MySQL на Beget, прогон производительности и доступности, правки |
| 6 | Запуск, Telegram-канал, первый публичный дайджест |

После запуска: первой функцией — проверка уровня и программа развития (v1.1, D22); еженедельный дайджест и перепроверка, 2–4 подборки в месяц; затем H2 и H5 по данным Метрики.
