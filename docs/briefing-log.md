## Фаза 0 — исследование рынка (10.09.2026)

Матрица: 34 ресурса (22 EN, 12 RU). Лидеры по форматам: Mobbin / Refero (референсы, пейволл), Page Flows (флоу-видео), NN/g / Smashing / UX Collective (медиа), Toools.design / UX Tools (каталоги), Growth.Design / Built for Mars (кейсы «почему»), Laws of UX / Checklist Design (справочники, не обновляются). Рунет: vc.ru/design, Skillbox Media, Дизайн-кабак, Дайджест Ветрова, Telegram-каналы; UX Journal затух с 2025.

Дыры: (1) референсы за пейволлом, из РФ не оплатить; (2) нет разборов «почему так»; (3) B2B/enterprise/data-heavy не покрыт; (4) AI-UX паттерны разбросаны, на русском нет; (5) каталоги «гниют» без дат и фильтров; (6) в рунете нет структурированного сборника.

Гипотезы дифференциации: H1 живой каталог с фильтрами и датой проверки; H2 библиотека решений «почему так»; H3 статус доступности из РФ + локальные аналоги; H4 трек B2B/enterprise; H5 AI-UX хаб на русском; H6 маршруты обучения из бесплатных материалов; H7 чеклисты, связанные с примерами. Приоритет по исследованию: H1+H3 → H2 → H5/H4 → H6/H7.

Оговорка: Reddit недоступен для краулера, дыры подтверждены Product Hunt, vc.ru, Habr, NN/g, UX Tools.

## Раунд 3 — углубление (10.09.2026)

| # | Категория | Вопрос | Ответ заказчика |
|---|---|---|---|
| 9 | Контент | Типы записей каталога | Инструменты и сервисы; учебные материалы; ассеты и шаблоны; сообщества/каналы/рассылки/вакансии (все четыре) |
| 10 | Бренд | Голос редакторской оценки | Редакция под брендом + имя куратора. Название/домен не названы |
| 11 | Технология | Хостинг | Ещё нет, подобрать российский хостинг |
| 12 | MVP | Объём и срок | 100–150 записей + 8–10 подборок, 4–6 недель |

**Резюме**
- ✅ Четыре типа записей → четыре post type (или один `resource` с типом-таксономией) со своими полями.
- ✅ Голос: бренд + куратор; у оценок виден автор.
- ✅ Хостинг: российский, требования — PHP 8.3, MySQL 8, HTTPS, SSH/WP-CLI; выбор до запуска.
- ✅ MVP: 100–150 записей, 8–10 подборок, 4–6 недель.
- 🤔 Допущение: 4 типа на 100–150 записей = 25–40 на тип; на старте перекос в инструменты и учёбу (главные для junior), сообщества — минимум. Уточнить в раунде 4.
- 🤔 Допущение: аккаунтов пользователей в MVP нет (UGC не выбран); подписка на дайджест — через внешний сервис рассылки.
- ❓ Название и домен — открыто (не блокирует структуру, блокирует брендинг темы).
- ❓ Визуальный стиль, тёмная тема, правила маркировки партнёрок/рекламы.
