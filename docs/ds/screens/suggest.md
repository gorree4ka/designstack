## Composition

- `parts/header.html` → шапка; текущего пункта нет: формы в меню нет.
- `core/breadcrumbs` → «Главная › Предложить ресурс».

- `core/post-content` с классом `ds-prose` → вводная строка не шире 70 знаков (заготовка, текст пишет этап 16).
- block `designstack/suggest-form` → форма целиком: адрес, название, комментарий, почта, согласие со ссылкой на «Политику данных», поле-ловушка и кнопка «Предложить ресурс».
- `parts/footer.html`.

### /suggest/thanks/
- `templates/page.html`: крошки «Главная › Предложить ресурс › Спасибо», H1 «Спасибо!», текст и кнопка «Вернуться в каталог» — в содержимом страницы.

## Data

| Блок | Что показывает | Источник |
|---|---|---|
| `core/post-content` | вводную строку и текст «Спасибо» | содержимое страниц |
| `designstack/suggest-form` | поля, согласие, ловушку и кнопку | блок плагина этапа 12 |

## Edge cases

- Состояния формы — ошибки полей, отправка, сбой, лимит, дубль — рисует тот же блок; включает их этап 14.
- Прямой заход на «Спасибо» без отправки показывает ту же страницу.
- Любой хвост после `/suggest/`, кроме `thanks/`, — 404.

### Матрица состояний (этап 14)

| Блок | Состояние | Как закрыто |
|---|---|---|
| Форма | по умолчанию | пять полей, согласие, одна залитая кнопка |
| Форма | ошибки полей | сводка «Проверь форму» над формой, фокус на ней, сообщение у каждого поля, введённое возвращается как напечатано |
| Форма | отправка | кнопка получает `aria-busy` и подпись «Отправляем…», второй клик не отправляет |
| Форма | успех | переход на `/suggest/thanks/`, запись «на утверждении», письмо куратору в журнале |
| Форма | дубль | «Penpot уже есть в каталоге» со ссылкой, записи нет |
| Форма | лимит | четвёртая отправка за час — сообщение о лимите, записи нет |
| Форма | без nonce | «Не получилось отправить…», записи нет |
| Форма | ловушка заполнена | бот видит «Спасибо», записи и письма нет |
