# Screen: Страница ресурса (resource)

**Wireframe:** docs/ia/wireframes/resource.md · **Шаблон:** templates/single-resource.html · **URL:** /resource/{slug}/
**Партия:** 1 «Каталог» · **Статус:** verified

## Composition

### header
- `parts/header.html`. Текущий пункт меню — раздел типа ресурса.

### breadcrumbs
- `core/breadcrumbs` с классом `ds-breadcrumbs`: «Главная › Инструменты › Figma». Среднее звено — раздел по типу, название берётся из карты разделов, а не из термина.

### resource-layout (локальная композиция `.ds-detail`)
- `core/group {"className":"ds-detail"}`: от 900 — две колонки, слева 2/3, справа 1/3, зазор `space-8`; до 900 — одна колонка в порядке шапка → факты → оценка → аналоги.
- Ширина `wide` (1360, D41).

### resource-hero (левая колонка)
- block `designstack/resource-hero` собирает первый экран целиком: плитка логотипа `size-tile-lg` → H1 с названием → подпись типа `.ds-card__type` (не ссылка, D35) → вердикт крупнее текста → метки цены, доступа и оплаты (`ds-badges`) → плашка состояния (`ds-notice--dead|changed|stale`) → кнопка «Перейти на сайт» (primary lg, новая вкладка) и строка «Проверено 3 сен 2026».
- H1 внутри блока, а не отдельным `core/post-title`: логотип, название и подпись типа стоят одной строкой, разорвать её отдельным блоком нельзя.
- У закрытого ресурса кнопки перехода нет; если аналог есть — в плашке кнопка «Показать аналог» на `#analogs` (D31).

### resource-facts (правая колонка)
- block `designstack/resource-meta` → `.ds-facts`: пары «подпись — значение», пустое необязательное поле не выводится. Поля своего типа идут после общих.

### curator-review (левая колонка)
- block `designstack/curator-review` → `.ds-review`: H2 «Оценка куратора» и три подписанные части — «Кому подходит», «За что», «Когда не подойдёт» — плюс подпись куратора ссылкой на `/about/#curator`.
- Без «Когда не подойдёт» запись не публикуется (D32), поэтому третья часть на опубликованной странице есть всегда.

### analogs (якорь `#analogs`)
- block `designstack/resource-analogs` → H2 и сетка карточек из поля `ru_alternative`. Заголовок по D187: у ресурса с проблемой из России (закрыт, не открывается, открывается с перебоями, платный и не оплачивается картой РФ или только через посредника) — «Аналог, который работает из России» / «Аналоги, которые работают из России», у остальных — «Аналог» / «Аналоги»; число — по числу карточек. Нет аналога — блока нет.

### footer
- `parts/footer.html`.

## Edge cases

- Закрытый ресурс — `/resource/invision/`: плашка «Закрыт», кнопки «Перейти на сайт» нет, есть «Показать аналог», блок аналогов ниже.
- Без аналога — `/resource/laws-of-ux/`: блока `analogs` нет, кнопки «Показать аналог» нет.
- Бесплатный ресурс — метки и строки оплаты нет (D28).
- Давно не проверяли — плашка `stale` появляется у записи старше 90 дней; в демо-наборе такие есть.
- Незаполненное необязательное поле — строки в фактах нет.
- Черновик или несуществующий адрес — 404; `/resource/` без слага — 404 (D65).
- Переполнение: название в 80 знаков переносится и не обрезается; длинная `price_note` переносится под значением цены.

## Локальные композиции

- `ds-detail` — две колонки страницы ресурса (2/3 и 1/3 от 900). Пока встречается один раз; второй кандидат — страница «О проекте» в партии 4, тогда помечаем к выносу.

## Решения состава

- r1. Первый экран собирает один блок, а не набор core-блоков: логотип, название и подпись типа стоят одной строкой, а вердикт, метки, плашка и кнопка перехода зависят от одних и тех же полей — разрезать их на отдельные блоки значит четыре раза читать ту же запись и четыре раза ошибиться в порядке.
- r2. Подпись типа рядом с H1 — не ссылка: метка в каталоге не кликается (D35), а раздел и так стоит в крошках через строку выше.
- r3. Оценка куратора выводится тремя подписанными частями (D67), а не одним текстом: так видно, где ответ на «мне подойдёт?», а где на «когда не брать».
- r4. Блок аналогов показывает те же карточки, что и списки каталога, без облегчённого вида: аналог выбирают так же, как ресурс, — по цене, доступу и дате проверки.
- r5. Подпись куратора остаётся с именем-заглушкой «Мария Петрова» и ссылкой на `/about/#curator`: страница «О проекте» появится в партии 4, имя ждёт решения O2.

## Блок аналогов — решения состава (P28, 30.09.2026)

Лист решений: https://claude.ai/artifact/P3DdLtvq3iG7hac4k4r3yo

1. Заголовок зависит от того, есть ли у ресурса проблема из России: «Аналог, который работает из России» или «Аналоги». Решил так, потому что прежний заголовок обещал российский сервис, а в 32 парах из 42 стоял зарубежный; у бесплатного открытого ресурса обещание про Россию лишнее.
2. Пара остаётся, только если аналог делает то же дело и сам не болеет той же проблемой: открывается из России, а при проблеме с оплатой — бесплатный или оплачивается из России. Решил так, потому что аналог с той же проблемой (Jitter → Rive, Motiff → Figma) и аналог другого назначения (SVGOMG → Squoosh) не помогают.
3. Из 42 пар 29 оставить, 13 снять, одну добавить: Umami → Яндекс Метрика.
4. Кнопка «Показать аналог» и событие `ru_alternative_click` не меняются; меняются подпись поля в админке и словарь.
5. Что аналог российский, говорит только метка «Российский» на карточке.
