# Screen: Тема (topic)

**Wireframe:** docs/ia/wireframes/topic.md · **Шаблон:** templates/taxonomy-topic.html · **URL:** /topic/{slug}/
**Партия:** 1 «Каталог» · **Статус:** verified

## Composition

### header
- `parts/header.html`. Текущего пункта нет: тем в меню нет (D35).

### breadcrumbs
- `core/breadcrumbs` с классом `ds-breadcrumbs`: «Главная › Прототипирование», без звена «Темы» (D35).

### page-title
- block `designstack/archive-header` → H1 с названием темы и `.ds-meta` с числом выдачи.

### topic-intro
- `core/term-description` с классом `ds-page-header__lead`. Описания у терминов пока нет — блок ничего не печатает, строки на странице не появляется. Тексты ставит этап 16.

### child-topics
- Ряд ссылок на дочерние темы. Дочерних тем в каталоге нет — блока на странице нет; разметку добавит этап 16 вместе с деревом тем.

### type-filter
- block `designstack/filter-chips {"variant":"choice"}` → `.ds-chips.ds-chips--choice`: «Все» (текущий, без ссылки) · «Инструменты» · «Учёба» · «Ассеты» · «Сообщества».
- Ссылки ведут на тот же адрес с `?resource_type=…`; выборку по параметру делает этап 14, сейчас выдача не меняется.

### card-grid
- block `designstack/resource-list {"source":"archive","layout":"grid"}`: смешанная выдача всех типов, подпись типа в карточке обязательна.

### pagination
- block `designstack/pagination`. На `/topic/ux-research/` ресурсов 12 — страниц две, ряд виден.

### footer
- `parts/footer.html`; в списке тем подвала текущая тема остаётся ссылкой (снятие ссылки — этап 14, это чтение текущего запроса).

## Data

| Блок | Что показывает | Источник |
|---|---|---|
| `designstack/archive-header` | название темы и число выдачи | термин `topic` + `found_posts` |
| `core/term-description` | описание темы, если заполнено | поле термина |
| `designstack/filter-chips` | пять значений типа | таксономия `resource_type` |
| `designstack/resource-list` | карточки темы | основной запрос архива |

## Edge cases

- Тема без ресурсов → `empty-state {variant: section}` «В этой теме пока нет ресурсов» и ссылка «Предложить ресурс»; чипсов и пагинации нет. Проверяется на `/topic/accessibility/` и `/topic/ai-for-designers/` — обе пустые.
- Одна карточка в выдаче — `/topic/web-landings/`: карточка прижата влево, ширина колонки не меняется.
- Две страницы — `/topic/ux-research/` (12 ресурсов): на второй странице «Назад» активна, «Вперёд» — нет.
- Страница за пределами — `/topic/ux-research/page/9/` → 404.
- Несуществующая тема — 404.

### Матрица состояний (этап 14)

| Блок | Состояние | Как закрыто |
|---|---|---|
| Список | с данными | `/topic/ux-research/` — 10 карточек, смешанные типы |
| Список | пустая тема | `/topic/accessibility/` — 200, пустое состояние, `noindex`, чипсов и пагинации нет |
| Список | одна карточка | `/topic/web-landings/` — карточка прижата влево |
| Чипсы типа | выбран тип | `?resource_type=tool` — 2 из 10, «Все» становится ссылкой |
| Пагинация | две страницы | `/topic/ux-research/page/2/` — 200; фильтр сохраняется в адресе страницы |
| Пагинация | за пределами | `page/9/` → 404 |

## Tokens used

Те же, что в карте раздела, плюс `size-measure-lead` у описания темы.

## Icons

circle-check, triangle-alert, circle-x, clock, external-link, chevron-left, chevron-right.

## Локальные композиции

- `ds-archive` — та же раскладка, что в разделе, но без левой колонки: на теме панели фильтров нет, поэтому группа идёт в одну колонку. Отдельного класса не заводим.

## Решения состава

- p1. Ряд типов показан пятью чипсами с «Все» в начале, как в вайрфрейме, хотя выборка появится на 14: без ряда страница темы визуально не отличается от раздела.
- p2. Описание темы и дочерние темы не выводятся, пока их нет в данных: пустой заголовок «Описание» хуже, чем его отсутствие.
- p3. Пустая тема отвечает 200 с пустым состоянием, а не 404 (US-21): тема — посадочная страница, она может наполниться позже.

## Чеклист страницы

- [ ] Ряд типов помещается в строку на 1440 и переносится на 375 без горизонтальной прокрутки.
- [ ] Текущий чипс «Все» отличается от остальных и не кликается.
- [ ] На `/topic/accessibility/` вместо сетки — пустое состояние с иллюстрацией и ссылкой «Предложить ресурс».
- [ ] На `/topic/web-landings/` одна карточка прижата влево и не растянута на всю ширину.
- [ ] На `/topic/ux-research/` видна пагинация, вторая страница открывается.
- [ ] В карточках смешанной выдачи подпись типа стоит у каждой.
