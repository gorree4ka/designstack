## Composition

- block `designstack/not-found` → `empty-state {variant: not-found}`: иллюстрация, H1 «Такой страницы нет», строка «Адрес мог измениться или в нём опечатка. Найди ресурс поиском или открой раздел.»
- block `designstack/search-form {"variant":"home"}` → крупное поле поиска.
- pattern `designstack/entry-tiles` → четыре входа в разделы.

## Edge cases

- Заголовок пустого состояния на этой странице — единственный h1 страницы.
- 404 отдают также `/resource/`, `/level/*`, `/skill/*`, `/tag/*`, архивы дат и страницы за пределами пагинации.
