# Screen: Раздел каталога (tools · learn · assets · community)

**Wireframe:** docs/ia/wireframes/tools.md · **Шаблон:** templates/taxonomy-resource_type.html · **URL:** /tools/ /learn/ /assets/ /community/
**Партия:** 1 «Каталог» · **Статус:** verified

Один шаблон на четыре раздела: заголовок, строку выдачи и набор групп фильтров даёт тип из текущего архива. Отдельных файлов `taxonomy-resource_type-tool.html` не заводим — разделы отличаются только данными.

## Composition

### header
- `parts/header.html` → паттерн `site-header`. Текущий пункт меню — раздел (`aria-current="page"` ставит `core/navigation`).

### breadcrumbs
- `core/breadcrumbs` с классом `ds-breadcrumbs`. Путь «Главная › Инструменты»: последнее звено без ссылки ставит ядро.
- Название звена берётся не из термина: термин зовётся «Инструмент» (подпись типа в карточке), раздел — «Инструменты». Карту «слаг → название раздела» держит плагин, крошки правит фильтр.

### page-title
- block `designstack/archive-header` → `.ds-page-header`: H1 с названием раздела + `.ds-meta` с числом выдачи («7 ресурсов», склонение по числу).
- Строка выдачи считает записи текущего архива, а не всего каталога.

### catalog-layout (локальная композиция `.ds-archive`)
- `core/group {"className":"ds-archive"}`: от 900 — колонка `size-sidebar` (280) и выдача; до 900 — одна колонка. Та же раскладка стоит на пяти адресах, поэтому класс уезжает в `patterns.css` мини-циклом 11 (правило 3+).
- Ширина контента — `wide` (1360, D41), не `contentSize`.

### filter-panel (левая колонка)
- block `designstack/filter-panel` → `.ds-filters.ds-filters--sidebar`. Набор групп по типу архива: инструменты — Тема · Цена · Доступ из РФ · Оплата из РФ · Платформа · Грейд; учёба — Формат · Грейд · Язык · Цена; ассеты — Лицензия · Формат файла · Кириллица; сообщества — Платформа · Есть вакансии.
- Значения — из перечислений плагина и списка тем; подписи — из `docs/VOICE.md`.
- Выборку панель не делает: «Применить» перезагружает адрес с параметрами, которые пока не читаются (этап 14).

### active-filters (над выдачей)
- block `designstack/filter-chips` → `.ds-chips.ds-chips--removable`. Пока фильтров нет, ряд состоит из одной кнопки «Фильтры» — она видна до 900 и открывает панель на этапе 14.

### card-grid
- block `designstack/resource-list {"source":"archive","layout":"grid"}` → `.ds-resource-list--grid` с карточками `resource-card`: 3 колонки от 1200, 2 от 600, 1 меньше.
- Карточки берутся из основного запроса архива, поэтому сходятся со страницей пагинации и с числом выдачи.

### pagination
- block `designstack/pagination` → `.ds-pagination`. Выводится, только если страниц больше одной; на семи ресурсах в разделе блока нет.

### footer
- `parts/footer.html` → паттерн `site-footer`.

## Data

| Блок | Что показывает | Источник |

## Edge cases

- Раздел без ресурсов → `empty-state {variant: section}` с заголовком «В разделе пока нет ресурсов» и ссылкой «Предложить ресурс»; панель фильтров и пагинация не выводятся. На демо-данных все четыре раздела заполнены, поэтому состояние проверяется на теме без ресурсов — `/topic/accessibility/`, блок тот же.
- Пустая выдача фильтров (`empty-state {variant: filters}`) — этап 14: без чтения параметров её нечем вызвать.
- Страница за пределами — `/tools/page/2/` → 404 (в разделе одна страница).
- Переполнение: название в 80 знаков — карточка «Тестограф: конструктор опросов, анкет и тестов для исследований и обратной связи» из демо-набора; вердикт до трёх строк; последний неполный ряд прижат влево.
- Карточка закрытого ресурса — `/tools/` содержит InVision: плашка «Закрыт», вместо «Перейти на сайт» — «Показать аналог».

## Локальные композиции

- `ds-archive` — две колонки раздела. Встречается на пяти адресах (четыре раздела и тема) → вынос в `patterns.css` мини-циклом 11.

## Решения состава

- t1. Заголовок и крошка раздела — «Инструменты», а не название термина «Инструмент»: термин подписывает тип в карточке в единственном числе, и «Учебный материал» в шапке раздела вместо «Учёба» читалось бы как другая страница. Карта слагов лежит в плагине рядом с адресами разделов.
- t2. Панель фильтров показана целиком, с настоящими значениями, но пока не фильтрует — так на листе и на скриншотах виден настоящий раздел, а этап 14 включает выборку без перевёрстки.
- t3. Число выдачи — «7 ресурсов» со склонением по числу, а не «Найдено: 7»: словарь уже держит форму «1 ресурс, 2 ресурса, 5 ресурсов».
- t4. Один шаблон на четыре раздела, набор групп фильтров меняется по типу — решил так, потому что разделы отличаются только данными, а четыре файла разошлись бы при первой же правке.
- t5. Порядок карточек по умолчанию — сначала недавно проверенные (D40); это порядок каталога, а не фильтр, поэтому он ставится здесь, а не на 14.
- t6. Пагинация выводится только при двух и более страницах: на семи ресурсах ряд «Назад · 1 · Вперёд» был бы мусором.

## Чеклист страницы

- [ ] На 1440 в первом экране видны крошки, H1, число выдачи, панель фильтров и первый ряд карточек.
- [ ] Заголовок раздела и крошка — «Инструменты», «Учёба», «Ассеты», «Сообщества»; подпись типа в карточке остаётся в единственном числе.
- [ ] Карточки в ряду одной высоты, последний неполный ряд прижат влево.
- [ ] Закрытый ресурс отличается плашкой и кнопкой «Показать аналог», а не только цветом.
- [ ] Видно, что кликается: карточка и кнопка отличаются от метки и мета-строки.
- [ ] На 375 панель фильтров уходит под кнопку «Фильтры», сетка в одну колонку, горизонтального скролла нет.
- [ ] Длинное название не выдавливает нижнюю строку карточки за край.
