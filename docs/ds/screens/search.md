## Composition

- block `designstack/search-results`: H1 «Поиск» → поле поиска с запросом (`search-form` вариант `results`) → число найденного «2 результата» → карточки ресурсов и записей одной сеткой.
- Ничего не нашлось → `empty-state {variant: search}`: «По запросу «…» ничего нет», подсказка и ссылка «Предложить ресурс».
- block `designstack/pagination` — страниц меньше двух, блока нет.

## Data

| Блок | Что показывает | Источник |
|---|---|---|
| `designstack/search-results` | запрос, число найденного и карточки | основной запрос поиска WordPress |

## Edge cases

- Пустой запрос — только заголовок и поле.
- Ничего не нашлось — пустое состояние с запросом в заголовке.
- Витрина дизайн-системы в выдачу не попадает: служебная страница.

### Матрица состояний (этап 14)

| Блок | Состояние | Как закрыто |
|---|---|---|
| Выдача | с данными | поиск идёт по названию, вердикту и трём частям оценки |
| Выдача | ничего не нашлось | запрос повторён в заголовке, подсказка и «Предложить ресурс» |
| Выдача | длинный запрос | в заголовке обрезается до 60 знаков, в поле остаётся целиком |
| Выдача | разметка в запросе | экранируется: тег в страницу не попадает |
| Выдача | черновики | в выдачу не попадают |

## Решения состава

- s5. Выдача — то, что нашёл поиск ядра: ресурсы и записи одной сеткой, в порядке ядра. Ранжирование и фильтры доводит этап 14.
- s6. Число найденного и показанное совпадают: страницы тоже выводятся карточкой записи, иначе счёт врёт.
