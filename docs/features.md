# Функции DesignStack

Версия 1.0 от 11.09.2026, **утверждена заказчиком 11.09.2026** вместе с ТЗ (`docs/spec.md`). Источники: бриф 1.1 (`docs/brief.md`), анализ конкурентов (`docs/research/competitive_analysis.md`, дальше CA), персоны (`docs/personas.md`), журнал решений (`docs/DECISIONS.md`). Интервью не проводились: этап 05 пропущен осознанно (D21).

## Как читать

- **ID** `F-NN` присваивается один раз и не меняется: на него ссылаются user stories, этапы 13–15 и `docs/ds/screens/*.md`.
- **Источник** — точная ссылка: `brief §5.1`, `CA 2.5 только у нас #3`, `CA 4.4 ур. 4`, `CA 4.5 перенять #2`, `CA 4.6 избежать #1`, `CA 5.1 дифф. #2`, `П1 инсайт 2`, `D16`.
- **Персона:** П1 — junior-switcher (primary), П2 — middle-designer (secondary), П3 — lead-mentor (tertiary).
- **Вид.** «Функция» — то, что делает посетитель или редакция. «НФТ» — нефункциональное требование к платформе из brief §7–§8: оно обязательно по брифу, его порог и способ проверки — в `docs/spec.md`, раздел 7. Критерии MoSCoW и доля Must считаются только по функциям. Это допущение этапа, записанное в шапке ТЗ.
- **Уточняет F-NN** — функция частично перекрывает другую, но проверяется отдельно.
