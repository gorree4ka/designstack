# Российский взгляд: цена, доступ, оплата

Обе машины проекта выходят в сеть из Казахстана: рабочая (`ipinfo.io` → `KZ, AS202958 Hoster.KZ,
Almaty`) и машина заказчицы (её слова 15.09.2026). Страницы тарифов и доступ локализуются по стране
посетителя — 15.09.2026 IxDF показал Казахстану $12, а России $22 за то же членство. Поэтому
цифра, снятая отсюда, в каталог не попадает: она про другую страну.

Все три скрипта сами замеряют страну и без RU не работают. Это не перестраховка: браузер здесь
выглядит обычным и молча отдаёт казахстанские цены, отличить их по кадру невозможно.

## Три пути

**1. Доступ — с сервера.** Список адресов собирает `python scripts/collect_ru_urls.py` (берёт со
страницы ресурса ссылки «Войти», «Тарифы», а не главную), файл уезжает на сервер, там:

```
python3 scripts/check_ru_access.py          # отчёт в docs/research/ru-access/<дата_время>.md
```

Итог «открывается» значит только ответ 2xx без текста о блокировке. Код **451** — самое твёрдое
доказательство `ru_open = blocked` (Readymag, Whimsical, 14.09.2026). Вход, регистрацию и оплату
скрипт не проверяет.

**2. Цена в разметке — с сервера.** Когда цена лежит в HTML:

```
python3 scripts/ru_prices.py scripts/<список>.txt       # строка списка: «адрес | слаг записи»
```

**3. Цена на странице со скриптами — браузер здесь, адрес российский.** Если цену привозит
JavaScript уже после загрузки (роботу достаётся пустой документ), нужен настоящий браузер:

```
ssh -f -N -D 1081 -o ExitOnForwardFailure=yes designstack     # туннель, выход 5.101.157.244, Петербург
PYTHONIOENCODING=utf-8 python scripts/ru_browser_prices.py .tmp/<список>.txt --port 1081 --date <ГГГГ-ММ-ДД>
taskkill //F //IM ssh.exe                                      # закрыть туннель
```

Кадры ложатся в `docs/content/sources/<дата>_<слаг>-pricing.png` — это источник, на который потом
ссылается запись.

## Грабли

- **Тариф за логином.** Recraft не показывает планы неавторизованному даже из РФ. Тогда цена
  берётся со скриншота заказчицы, а в `docs/content/queue.md` пишется оговорка: кадр снят из
  Казахстана, сумма в долларах без НДС и, вероятно, совпадает с глобальной.
- **Цен на странице не видно.** Значит, публичной цены нет (cosmos — «Content not found», shots —
  404): `price_note` остаётся пустым, модель оплаты в записи не выдумывается.
- **Дата-центр ≠ домашний провайдер.** Сервер отдаёт 200 там, где у людей всё грузится рывками
  (значение `unstable`, D103). Прогоном с сервера такую метку ни подтвердить, ни снять — она
  ставится только по описанному факту.
- **Роботу 200, браузеру блок.** `check_ru_access.py` получил от Rosenfeld Media 200 и написал
  «открывается», а настоящий браузер с того же российского адреса увидел страницу Cloudflare
  «Sorry, you have been blocked». Итог скрипта «открывается» для сайта за Cloudflare — только гипотеза:
  его подтверждает кадр `ru_browser_prices.py` через туннель. Способ проверки — в кадре нет «Attention
  Required! | Cloudflare» и «you have been blocked». Случай: 28.09.2026, Surveys That Work и Card Sorting.
- **Таймаут соединения и молчащий DNS — это не «сервер лежит».** InformIT и Peachpit (Pearson) с сервера
  не резолвятся локальным DNS хостинга, а по адресу от 8.8.8.8 соединение висит до таймаута и на 80, и
  на 443 порту; из Казахстана тот же адрес отдаёт 200, туннель даёт `ERR_SOCKS_CONNECTION_FAILED`.
  Проверка — `curl --resolve <хост>:443:<адрес>` с сервера и тот же запрос отсюда. Случай: 28.09.2026.
- **Цена частного продавца — не цена книги.** На books.ru вкладка «Бумажная книга» у распроданного
  издания показывает цену продавца «оплата и доставка по договорённости», а цена PDF от издательства
  лежит на вкладке «Электронная книга» (`?show=1` в адресе). Случай: 28.09.2026, «Информационная
  архитектура в Интернете» — 200 ₽ у частника, 190 ₽ за PDF.
- **`'charmap' codec can't encode`** — запускать с `PYTHONIOENCODING=utf-8`.

## Куда попадает результат

1. Поле `price_note` и статусы записи меняются навыком `live-sync` — локально и на живом сайте сразу.
2. В `docs/content/queue.md` — строка прогона: дата, что исправлено, что подтвердилось без правок,
   где кадр. Цифра без источника и даты в каталог не идёт (навык `source-check`).
3. Метка и вердикт не повторяют друг друга — проверка `python scripts/check_voice.py`.
