# Самопроверка до показа

Заказчица 10.09.2026: «не торопись, делай как надо». Доклад «готово» без прогона проверок —
это обещание, за которое расплачивается она. Проверка пишется скриптом: глазами по сто сорока
записям или двумстам строкам документа человек не пройдёт, а скрипт проходит одинаково каждый раз.

## Скелет проверки

```python
checks = []                      # (имя, условие) — каждое условие проверяемо кодом

def check(name, ok, note=""):
    checks.append((name, bool(ok), note))

# … сами проверки …

fails = [c for c in checks if not c[1]]
print("проверок: %d, провалов: %d" % (len(checks), len(fails)))
sys.exit(1 if fails else 0)
```

Обязательные детали, каждая куплена ошибкой:

- **Счётчик проверок.** Скрипт печатает, сколько проверок выполнено, и это число сверяется
  с ожидаемым. 10.09.2026 замена в `selfcheck_03.py` молча не сработала, проверка не выполнилась,
  а «зелёное» уже было доложено. Ноль провалов при двадцати восьми проверках вместо тридцати —
  это провал, а не успех.
- **Кодировка.** Запуск с `PYTHONIOENCODING=utf-8`: консоль здесь cp1251, и `£` или `₽` в выводе
  роняют скрипт целиком.
- **Цитаты — дословно.** Утверждение в «ёлочках» сверяется с корпусом источника посимвольно,
  а не пересказом.
- **База сравнения — не время файла.** `Edit` пересоздаёт файл, поэтому `ctime` как отметка
  «менялось после проверки» даёт ложные срабатывания: фиксируй метку времени явно.
- **Чтение до записи.** Скрипт, который правит готовый документ, сначала читает его целиком;
  пустой результат не пишется; переносы строк сохраняются (`newline=""`).

## Что проверять по типам работы

| Работа | Проверки |
|---|---|
| Документ | все разделы скелета на месте; каждый путь из документа существует; цитаты дословны; нет внутренних путей `docs/…` в тексте, который увидит читатель |
| Страница сайта | `curl` отдаёт 200; `debug.log` без новых ошибок; `python scripts/check_tokens.py`; скриншот в обеих темах; на 375 нет горизонтального скролла |
| Тексты | `python scripts/check_voice.py --base <адрес>` — стоп-слова и повтор метки в вердикте |
| Записи каталога | обязательные поля по типу; дата проверки; цифра только с источником (навык `source-check`) |
| Ссылки | `python scripts/check_links.py` |

## Где живёт скрипт

Разовая проверка — в черновиках (`.tmp/` или папка сессии), она не нужна в репозитории.
Проверка, которую прогоняешь второй раз, переезжает в `scripts/` с docstring «зачем нужна»
и кодом выхода: так её можно повесить в хук.

## Доклад

В ответ заказчику идёт результат прогона, а не намерение: «проверок 42, провалов 0» или
честный список того, что не сошлось. Если проверить нельзя — так и написать, что не проверено.
