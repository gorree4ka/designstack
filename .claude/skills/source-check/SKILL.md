# Проверка утверждения по первоисточнику

Каталог держится на том, что его цифрам можно верить. Одна непроверенная цифра дороже десяти
ненаписанных: читатель, который поймал сайт на завышенном числе подписчиков, не вернётся.

## Классы ошибок, каждый найден на живых данных

| Класс | Случай | Как правильно |
|---|---|---|
| Число без источника | «Дизайн-кабак ≈ 15 000» против настоящих 4 250; Sidebar «≈ 100 000» против «~40k» на странице вендора для рекламодателей | ссылка на страницу, где число видно, и дата замера в `docs/content/queue.md`; для Telegram — `t.me/s/<канал>` |
| Цена без периода | Mobbin «$32» — это $120 в год или $45 в квартал | сумма, период и условие («$16 в месяц при оплате за год») |
| Цена не той страны | IxDF: Казахстану $12, России $22 | снимать только российским взглядом (навык `ru-check`) |
| Дата без первоисточника | «Figma ограничила доступ в сентябре 2024» — из пересказа | страница вендора или его справка; нет страницы — нет даты |
| Замер, которого не было | «проверено с российского IP (Новосибирск)» — город взят из часового пояса, а адрес был казахстанский | страну измеряет скрипт и печатает в отчёт |
| Обобщение вместо факта | «всё больше дизайнеров переходят на…» | конкретный источник или вычеркнуть |

## Порядок

1. Выписать утверждения, которые пойдут к читателю: числа, цены, даты, «работает / не работает».
2. По каждому открыть **первоисточник** — страницу вендора, его справку, открытое API, превью
   канала. Пересказ в статье, чужая подборка и прошлый наш отчёт первоисточником не считаются.
3. Записать: утверждение · адрес источника · дата, когда смотрели.
4. Расхождение — не повод «подправить на глаз»: меняется значение, а в `docs/content/queue.md`
   появляется строка, что было и что стало.
5. Чего первоисточник не подтверждает — не пишем. Пустое поле честнее красивой цифры.

## Когда запускать

- Перед публикацией записи, подборки, выпуска.
- При перепроверке каталога (`python scripts/check_links.py` показывает, что изменилось).
- Когда цифра пришла из отчёта AI-исследования: такие отчёты уверенно называют числа, которых
  нет на сайте вендора. 10.09.2026 сверка внешнего отчёта дала три исправления из четырёх проверок.

## Проверка

Число в записи → ссылка в очереди → дата замера. Нет любой из трёх частей — утверждение не готово
к публикации.
