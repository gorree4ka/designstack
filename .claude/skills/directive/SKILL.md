---
name: directive
description: Запустить директиву конвейера DesignStack по номеру (например «/directive 07» или «выполни директиву 07»). Читает карту 00_pipeline.md, проверяет предусловия и выполняет директиву поэтапно с апрувами.
argument-hint: "<NN> [аргументы директивы]"
allowed-tools: Read Write Edit Bash Glob Grep WebSearch WebFetch AskUserQuestion Agent
---

1. Прочитай `00_pipeline.md` — найди строку директивы с номером из `$ARGUMENTS` (первый токен). Если номера нет — покажи таблицу этапов и спроси, какой запускать.
2. Открой файл `NN_directive_*.md` и проверь раздел «Предусловие»: все входные артефакты существуют? Если нет — скажи, какая директива их создаёт, и предложи запустить её.
3. Выполняй директиву фаза за фазой. Точки апрува — через `AskUserQuestion`. Не перескакивай в следующую директиву.
4. По завершении обнови статус этапа в таблице `00_pipeline.md` (⏳ → ✅ с датой) и выведи блок «Финал» из директивы.

Аргументы: $ARGUMENTS
